# Unity GTA-like Test Task

Небольшая тестовая GTA-like сцена, созданная в рамках тестового задания.

## Unity Version

- Unity 6000.3.9f1
- Universal Render Pipeline (URP)

## Запуск проекта

1. Открыть Unity-проект из папки `TestTask`.
2. Открыть сцену:
   `Assets/_Project/Scenes/TestScene.unity`
3. Нажать Play.

`TestScene` также установлена как Scene 0 в Build Profiles.

## Возможности

- Управление персонажем от третьего лица
- Управляемый автомобиль
- Вход и выход из автомобиля
- Камеры персонажа и автомобиля на основе Cinemachine
- Свободное управление камерой автомобиля мышью
- Zoom камеры автомобиля колесом мыши
- Отдельный режим Free Camera по `Ctrl + C`
- Ограничение Free Camera разрешённой зоной
- Последовательная навигация по маршруту
- Продвижение по маршруту работает как пешком, так и на автомобиле
- UI с отображением текущей цели и расстояния до неё
- Контекстные подсказки взаимодействия
- Восстановление перевёрнутого автомобиля

- Сообщение о завершении маршрута

## Сцена

Тестовая сцена построена как компактная GTA-like карта с несколькими визуально различимыми зонами:

- **Start** — небольшая жилая / пригородная зона;
- **Station** — транспортная зона с дорогами и объектами станции;
- **Pier** — зона у воды с причалом и портовыми объектами;
- **Mountain** — возвышенная природная зона с отдельным автомобильным маршрутом.

Между зонами существует связанный проезжаемый маршрут. Пространство позволяет проверить перемещение как пешком, так и на автомобиле.

Для визуальной доработки сцены использованы бесплатные low-poly ассеты окружения, при этом исходная структура blockout-сцены и игровой маршрут сохранены.

Основной навигационный маршрут:

`Start → Pier → Mountain`

`Station` используется как дополнительная визуально выделенная зона сцены и не является обязательной точкой текущего маршрута.

## Маршрут

Навигационный маршрут настраивается через `RouteController`.

Точки маршрута хранятся в виде упорядоченного списка в Inspector. Новую точку можно добавить, удалить или изменить порядок существующих точек без изменения кода.

Каждая точка маршрута содержит:

- trigger collider;
- компонент `RoutePoint`;
- визуальный marker.

При запуске система отключает markers всех `RoutePoint` в сцене, после чего отображает только marker текущей цели.

Точки, которые существуют в сцене, но не входят в текущий маршрут `RouteController`, не отображаются.

После достижения текущей точки система автоматически активирует следующую.

После достижения последней точки отображается сообщение `ROUTE COMPLETE`, которое автоматически скрывается через несколько секунд.

### Free Camera

Free Camera включается и выключается сочетанием:

`Ctrl + C`

Управление:

| Input | Действие |
| --- | --- |
| W / A / S / D | Свободное перемещение |
| Mouse | Осмотр |
| Q | Движение вниз |
| E | Движение вверх |
| Shift | Ускоренное перемещение |
| Ctrl + C | Выход из Free Camera |

При включении Free Camera:

- управление персонажем и автомобилем временно отключается;
- Cinemachine Brain перестаёт управлять `MainCamera`;
- обычный gameplay UI скрывается;
- отображается отдельная подсказка управления Free Camera.

При выходе из Free Camera исходное состояние gameplay controls и UI восстанавливается.

На старте сцены отображается отдельная подсказка:

`[Ctrl + C] Free Camera`

### Ограничение Free Camera

Свободная камера не может покинуть разрешённую область уровня.

В Inspector можно указать несколько `BoxCollider` зон.

Это ограничивает свободный осмотр только игровой областью, не создавая одну большую прямоугольную границу вокруг всей карты.

## Модификация Vehicle Controller

Импортированный vehicle controller был расширен настраиваемой системой восстановления автомобиля.

Система обрабатывает два сценария:

1. автомобиль перевёрнут;
2. автомобиль застрял и не может самостоятельно продолжить движение.

### Восстановление перевёрнутого автомобиля

Если автомобиль достаточно сильно перевёрнут и движется со скоростью ниже заданного порога, игрок может нажать `R`.

Состояние переворота определяется сравнением направления `transform.up` автомобиля с мировым `Vector3.up`.

При восстановлении:

1. Обнуляется линейная скорость `Rigidbody`.
2. Обнуляется угловая скорость.
3. Автомобиль поднимается над поверхностью на заданную высоту.
4. Автомобиль возвращается в вертикальное положение.
5. Сохраняется его текущее направление по оси Y.

Когда восстановление доступно, отображается:

`[R] Recover Vehicle`

### Восстановление застрявшего автомобиля

Для stuck recovery используется отдельная проверка.

Автомобиль может быть признан застрявшим, если:

- игрок пытается двигаться вперёд или назад;
- скорость автомобиля остаётся ниже заданного порога;
- за заданное время автомобиль проходит только небольшое расстояние.

Обычный неподвижный автомобиль без попытки движения не считается застрявшим.

После определения stuck-состояния отображается:

`[Hold R] Reset Stuck Vehicle`

При удержании `R` автомобиль переносится в ближайшую настроенную `Recovery Point`.

`Recovery Points` задаются через Inspector и могут быть размещены в безопасных местах вдоль игрового маршрута.

Перемещение выполняется через `Rigidbody` с предварительным обнулением линейной и угловой скорости.

### Настройка Vehicle Recovery

Основные параметры доступны в Inspector компонента `CarController`.

#### Overturned Recovery

- `Enable Recovery`
- `Reset Height`
- `Max Reset Speed`
- `Upside Down Threshold`

#### Stuck Recovery

- `Recovery Points`
- `Stuck Detection Time`
- `Stuck Speed Threshold`
- `Stuck Max Travel Distance`
- `Stuck Recovery Hold Time`
- `Stuck Release Speed`

## Взаимодействие с автомобилем

Логика входа и выхода из автомобиля реализована отдельно от импортированного vehicle controller.

Основные скрипты:

- `Assets/_Project/Scripts/Interaction/VehicleSeat.cs`
- `Assets/_Project/Scripts/Interaction/PlayerVehicleInteractor.cs`

Система взаимодействия:

- показывает `[F] Enter Vehicle`, когда персонаж находится рядом с автомобилем;
- показывает `[F] Exit Vehicle` во время управления автомобилем;
- отключает управление персонажем во время вождения;
- включает управление автомобилем;
- переключает Cinemachine cameras;
- размещает персонажа в настроенной точке выхода после покидания автомобиля;
- отображает vehicle HUD только во время управления машиной.

## Камеры

Для персонажа и автомобиля используются Cinemachine cameras.

Автомобильная камера поддерживает:

- свободный orbit мышью;
- zoom колесом мыши;
- мгновенное переключение через Cinemachine Brain с `Default Blend = Cut`.

`Cut` используется для предотвращения нежелательной траектории blend при переключении камеры, например если автомобиль находится в нестандартном положении.

Отдельный `FreeCameraController` временно отключает управление Cinemachine Brain и напрямую управляет `MainCamera`.

## Навигация

Скрипты, связанные с навигацией, находятся в:

`Assets/_Project/Scripts/Navigation/`

Основные компоненты:

- `RouteController` — хранит упорядоченный маршрут и переключает текущую цель;
- `RoutePoint` — описывает отдельную точку маршрута и её trigger;
- `RouteParticipant` — позволяет одним и тем же route points работать для персонажа и автомобиля;
- `NavigationUI` — отображает текущую цель, расстояние и завершение маршрута;
- `RouteMarkerAnimation` — отвечает за простую анимацию marker текущей цели.

`RouteParticipant` используется как персонажем, так и автомобилем, благодаря чему одни и те же контрольные точки маршрута работают для обоих способов передвижения.

## Структура проекта

Unity-проект находится в:

`TestTask/`

`TestTask/Assets/_Project/Scripts/`

Основные директории:
