# Unity GTA-like Test Task

Небольшая тестовая сцена в стиле GTA, созданная в рамках тестового задания.

## Unity Version

- Unity 6000.3.9f1
- Universal Render Pipeline (URP)

## Возможности

- Управление персонажем от третьего лица
- Управляемый автомобиль
- Вход и выход из автомобиля
- Камеры персонажа и автомобиля на основе Cinemachine
- Свободное управление камерой автомобиля мышью и zoom колесом мыши
- Последовательная навигация по маршруту
- Продвижение по маршруту работает как пешком, так и на автомобиле
- UI с отображением текущей цели и расстояния до неё
- Контекстные подсказки для входа/выхода из автомобиля и восстановления машины
- Настраиваемое восстановление автомобиля после переворота
- Визуальный маркер текущей точки маршрута
- Сообщение о завершении маршрута

## Сцена

В тестовой сцене используются визуально различимые зоны:

- Start
- Station
- Pier
- Mountain

Основной навигационный маршрут проходит через обязательные точки:

`Start → Pier → Mountain`

## Маршрут

Навигационный маршрут настраивается через `RouteController`.

Точки маршрута хранятся в виде упорядоченного списка в Inspector. Новую точку можно добавить, удалить или изменить порядок существующих точек без изменения кода.

Каждая точка маршрута содержит:

- trigger collider;
- компонент `RoutePoint`;
- визуальный marker.

При запуске все route markers отключаются, после чего отображается только marker текущей цели. Точки, которые существуют в сцене, но не входят в текущий маршрут `RouteController`, не отображаются.

После достижения текущей точки система автоматически активирует следующую. После достижения последней точки отображается сообщение `ROUTE COMPLETE`, которое скрывается через несколько секунд.

## Модификация Vehicle Controller

Импортированный vehicle controller был расширен настраиваемой системой восстановления автомобиля после переворота.

### Что было изменено

В `CarController` была добавлена функция восстановления автомобиля.

Если автомобиль достаточно сильно перевёрнут и движется со скоростью ниже заданного порога, игрок может нажать `R`, чтобы восстановить его положение.

При восстановлении:

1. Останавливается линейное движение автомобиля.
2. Останавливается вращательное движение.
3. Автомобиль поднимается над поверхностью на заданную высоту.
4. Автомобиль возвращается в вертикальное положение.
5. Сохраняется его текущее направление по оси Y.

Такое ограничение позволяет избежать восстановления автомобиля на высокой скорости и делает функцию управляемой через Inspector.

### Настройка

Следующие параметры доступны в Inspector компонента `CarController` в разделе **Vehicle Recovery**:

- `Enable Recovery`
- `Reset Height`
- `Max Reset Speed`
- `Upside Down Threshold`

Восстановление автомобиля разрешено только если:

- `Enable Recovery` включён;
- автомобиль достаточно сильно перевёрнут;
- текущая скорость автомобиля ниже значения `Max Reset Speed`.

Когда восстановление доступно, на экране отображается подсказка `[R] Recover Vehicle`.

## Взаимодействие с автомобилем

Логика входа и выхода из автомобиля реализована отдельно от импортированного vehicle controller.

Основные скрипты:

- `Assets/_Project/Scripts/Interaction/VehicleSeat.cs`
- `Assets/_Project/Scripts/Interaction/PlayerVehicleInteractor.cs`

Система взаимодействия:

- показывает `[F] Enter Vehicle`, когда персонаж находится рядом с автомобилем;
- показывает `[F] Exit Vehicle` во время управления автомобилем;
- отключает управление персонажем во время вождения;
- включает управление автомобилем;
- переключает Cinemachine камеры;
- размещает персонажа в настроенной точке выхода после покидания автомобиля;
- отображает vehicle HUD только во время управления машиной.

## Навигация

Скрипты, связанные с навигацией, находятся в:

`Assets/_Project/Scripts/Navigation/`

Основные компоненты:

- `RouteController` — хранит упорядоченный маршрут и переключает текущую цель;
- `RoutePoint` — описывает отдельную точку маршрута и её trigger;
- `RouteParticipant` — позволяет одним и тем же route points работать для персонажа и автомобиля;
- `NavigationUI` — отображает текущую цель, расстояние и завершение маршрута;
- `RouteMarkerAnimation` — отвечает за простую анимацию marker текущей цели.

`RouteParticipant` используется как персонажем, так и автомобилем, благодаря чему одни и те же контрольные точки маршрута работают для обоих способов передвижения.

## Структура проекта

Основной код, добавленный для тестового задания, находится в:

`Assets/_Project/Scripts/`

Основные директории:

- `Interaction` — вход и выход из автомобиля;
- `Navigation` — маршрут, точки маршрута, markers и UI;
- `Vehicle` — дополнительная логика автомобиля, если она вынесена в отдельные компоненты;
- `Scenes` — тестовая сцена проекта.

Техническая спецификация предлагаемого Editor-инструмента для настройки маршрутов находится в:

`Docs/NavigationToolSpecification.md`
